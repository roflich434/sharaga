# Weather App - Приложение погоды

Веб-приложение для просмотра погоды в городах России.

## Технологии
- Python 3.10
- Flask
- JavaScript (fetch API)
- CSS3 (анимации)
- wttr.in API

## Функционал
- Выбор из 8 городов
- Прогноз на 3 дня
- Защита от DDOS (rate limiting)
- Логирование действий пользователей
- REST API

## Запуск
1. `pip install -r requirements.txt`
2. `python app.py`
3. Открой http://localhost:5000
